# Analisis de datos Airbnb - Grupo 30

Este proyecto realiza un Análisis Exploratorio de Datos (EDA) sobre el dataset de Airbnb.


## Ejecución 
Se clona el repositorio, se inicia el entorno virtual según el sistema operativo, en linux es:
- python3 -m venv venv
- source venv/bin/activate
- pip install -r requirements.txt
- jupyter notebook
